# Portfolio — Dhananjay Nautiyal

Static portfolio (plain HTML/CSS/JS, no build step). Live at
**https://dhananjay-nautiyal.github.io/portfolio**.

## Preview locally

```bash
cd portfolio
python3 -m http.server 8080
# open http://localhost:8080/
```

## Replace the resume

Overwrite `resume.pdf` with your real resume (keep the same file name —
the Download Resume buttons point to it).
